# Mestre da Nutrição AS — v1.0.0

Versão temporária de uso em navegador, derivada do Mestre da Nutrição CF.

A safra possui 6 fases fenológicas. Durante o jogo, a produtividade permanece oculta. O resultado final é construído pela soma do desempenho em cada fase e só é exibido na colheita.

Não há botão de instalação. O `service-worker.js` apenas limpa/desregistra caches antigos para evitar que versões anteriores permaneçam carregadas.
